# 06 · 前端设计规范

> 版本 v0.2 ｜ 2026-09-23 ｜ 状态：待评审
> 技术约束：Vue 3（CDN global build）+ ECharts 5（CDN），**无 npm 构建**；由 FastAPI 同源托管；全中文。
> 变更（v0.2）：M5 新增 §4.6 学习路径页与 §4.7 数据大屏，§1 视图表补两行，§2/§6 同步双主题令牌与真实目录；§4.1–§4.5 规范未改动。

## 1. 信息架构与页面

顶部为产品标题栏 + 六个视图 Tab（左）与健康状态点（右）；左侧可折叠二级面板、右侧主工作区。视图：

| 视图 | 路由锚点 | 核心内容 |
|---|---|---|
| 概览 | `#/overview` | 统计卡片（文档/实体/关系/分块/会话）、知识图谱缩略图、数据大屏入口、快速入口 |
| 知识图谱 | `#/graph` | 搜索框 + 类型筛选 + ECharts 力导向图 + 实体详情抽屉 |
| 学习路径 | `#/path` | 章节下拉 + 分层先修图 + 目标知识点必修链 + 触达标记 |
| RAG 问答 | `#/rag` | 左：会话列表；右：对话流（模式切换、引用卡片、流式答案） |
| ReAct 智能体 | `#/agent` | 左：会话列表/历史运行；右：对话流 + **步骤时间线** |
| 知识库管理 | `#/library` | 上传区、文档状态表、重建/删除操作 |

**数据大屏 `/screen` 不是 Tab，是另一个 HTML 页面**：独立深色令牌（`css/screen.css`，与 `app.css` 互不引用）、独立脚本（`js/screen/screen.js`，无 Vue 依赖），从概览页以新标签打开。两套生命周期互不干扰，工作台切页不影响投屏，投屏崩了也不影响演示主线（详见 §4.7）。

## 2. 设计令牌（CSS 变量，全局唯一来源）

```css
:root {
  --text-color: #1A1B1C;        /* 主文本 */
  --text-secondary: #6B7280;    /* 次文本 */
  --bg-color: #F6F7F9;          /* 页面冷白背景（现代简约白） */
  --card-color: #FFFFFF;
  --border-color: #E5E7EB;
  --accent: #8BC8EA;            /* 主强调（科技蓝） */
  --accent-deep: #2B6E94;       /* 强调文字（保证对比度） */
  --thought: #8BC8EA;           /* 思考-蓝 */
  --action: #E1B98F;            /* 行动-暖橙 */
  --action-deep: #9A6B2F;
  --observe: #A2DDAA;           /* 观察-绿 */
  --observe-deep: #3D7A33;
  --success: #52C41A; --warning: #FAAD14; --error: #EA6668;
  --radius: 12px; --gap: 16px;
  --font: 'Roboto','PingFang SC','Segoe UI',Arial,sans-serif;

```

- 工作台**只有浅色主题**；卡片微阴影（`0 1px 2px rgba(16,24,40,.05)`），禁止全局重阴影；
- 正文 13.5–14px、次要 12px、标题 16px/600；最小字号不低于 11px；
- 语义色同时配合图标/文字标签，不只靠颜色区分（思考/行动/观察各带中文标签）。

### 2.1 大屏令牌（`css/screen.css`，与 app.css 完全隔离）

深色大屏不复用上面的浅色令牌：两端各自一份 `:root`，互不 `@import`，改一边不会污染另一边。

```css
:root {
  --sc-bg: #050B1A;  --sc-panel: rgba(16,34,64,.55);  --sc-line: rgba(64,156,255,.22);
  --sc-text: #DCE9FF; --sc-dim: #6E86AD;
  --sc-cyan: #22D3EE; --sc-blue: #3B82F6; --sc-amber: #FBBF24; --sc-green: #34D399;
}
```

- 字号下限 **16px**（3 米外可读），比工作台高一档；数字用 `font-variant-numeric: tabular-nums` 防止滚动时宽度跳动；
- `html,body{overflow:hidden}`：等比缩放后不允许出现滚动条；
- 语义色只用于状态（正常/告警/中断），面板统一半透明深蓝 + 1px 亮边，靠发光而非阴影做层次。

## 3. 布局规范

- 最大内容宽度 1720px 居中（1920 宽屏下卡片近满幅铺开，避免大屏大量留白）；问答类视图采用 `280px 侧栏 + 1fr 主区`，窄屏（<900px）侧栏折叠为抽屉；
- 间距 8px 栅格（8/16/24）；卡片圆角 12px、内边距 12–16px；
- 不引入 UI 组件库，用少量通用类（`.card .btn .tag .empty`）统一控件；
- 分辨率下限 1366×768 不出现横向滚动。

## 4. 各视图详细设计

### 4.1 概览页

- 顶部 5 张统计卡片（数字 + 标签，数字来自 `/api/stats`，进入页面与建库完成后刷新）；
- 中部左侧一张只读迷你力导向图（取 `/api/graph?limit=120`，小节点不遮盖，仅度数 Top10 核心实体显示名称标签），右侧"实体类型分布"环图（纯前端按 type 聚合 `/api/graph?limit=500` 计算，不加后端端点）；
- 下部左侧"高频关系 Top 8"横向条图（按 edge.label 计数聚合，同上纯前端计算）；右侧"快速开始"三步引导（上传材料 → 浏览图谱 → 开始问答）。

### 4.2 知识图谱页

- 工具条：实体名搜索框（防抖 300ms）、实体类型多选（来自 `/api/graph` 的 types）、布局切换（力导向 P0 / 环形 P1）、"重新布局"按钮；
- 主画布：ECharts `series.type=graph, layout='force'`；节点按 type 固定配色（协议/设备/层次/地址/算法/概念各一色，图例常驻）；边标签默认隐藏、hover 显示关系；
- 交互：拖拽节点、滚轮缩放（`roam:true`）、点击节点 → 右侧抽屉展示描述、类型、一跳邻居列表、来源文档（点击来源展开 snippet）；选中节点后**持续邻接高亮**（选中节点与一跳邻居保持高亮、其余淡出；点击抽屉关联实体焦点随之切换，关闭抽屉取消高亮）；
- 性能：节点 >500 时按 limit 截断并显示提示；关闭无意义的持续动画，力导稳定后停止迭代（`force.layoutAnimation` 控制）；
- 空态：未建库时显示"请先到知识库管理上传课程材料"。

### 4.3 RAG 问答页

- 顶部检索模式 segmented 控件：naive / local / global / hybrid（默认 hybrid，附简短 tooltip 说明差异，便于现场对比讲解）；
- 对话气泡：用户右靠蓝底，助手左靠白底；助手回答逐字流式（SSE token）；
- **来源卡片**：`sources` 事件先于 token 到达，渲染为可折叠卡片列表（文档名 + snippet，命中关键词高亮）；
- 底部输入框（Enter 发送、Shift+Enter 换行），生成中显示"停止"（P1）与加载指示；
- 错误态：error 事件显示红色提示条与"重试"。

### 4.4 ReAct 智能体页（重点页面）

#### 4.4.1 时间线组件（components/timeline.js）

- 垂直时间线，左侧步骤序号/图标 + 连接线，右侧卡片；三类卡片样式：
  - **思考 THOUGHT**：左边框 3px 蓝色，标题"思考"，内容为模型思考文本；
  - **行动 ACTION**：左边框橙色，标题"行动 · {工具中文名}"，参数以等宽字体 chip/代码块展示（JSON 高亮键名即可，不引第三方库）；
  - **观察 OBSERVATION**：左边框绿色（失败红色），标题"观察 · 成功/失败 · {elapsed_ms}ms"，文本结果 + "结构化结果"可展开区（subnet 结果渲染为键值表、lpm trace 渲染为逐行表）；
- 卡片按 `step_no` 分组，同一步内 thought→action→observation 纵向排列并以细连线串联；
- 新事件到达时卡片插入 + 平滑滚动到底部（保留"用户向上滚动时不强制跟随"开关）；
- 最终答案区固定在时间线末尾，token 逐字输出，完成后折叠时间线细节（可再展开，保证答案在首屏）。
- **人工审批卡片（P1）**：收到 `interrupt` 事件时，在对应行动卡片下方插入审批条——展示待执行工具名与参数（参数可编辑），按钮为「批准执行 / 修改后执行 / 拒绝」，审批期间该步骤标记"等待人工"（琥珀色）；点击后 POST resume 端点，收到的新 SSE 流首帧为 `resumed`，事件**追加到同一条时间线**（不新建容器、不滚动重置）；thought 文本为空时合成"决定调用 {工具}"一行，不伪造推理。

#### 4.4.2 SSE 客户端（api.js）

```js
// 约定：postSSE(url, body, { onEvent }) 返回可中断的控制器
function postSSE(url, body, handlers) {
  const ctrl = new AbortController();
  fetch(url, { method:'POST', headers:{'Content-Type':'application/json'},
               body: JSON.stringify(body), signal: ctrl.signal })
    .then(async resp => {
      const reader = resp.body.getReader();
      const decoder = new TextDecoder();
      let buf = '';
      while (true) {
        const { value, done } = await reader.read();
        if (done) break;
        buf += decoder.decode(value, { stream:true }).replace(/\r/g, '');
        // 按 \n\n 切分 SSE 帧，解析 event:/data:，分发 handlers[event](JSON.parse(data))
        // （sse-starlette 输出 \r\n 行尾，先去掉 \r 再按空行分帧）
      }
    }).catch(err => { if (err.name !== 'AbortError') handlers.error({message:'连接中断，请重试'}); });
  return ctrl;
}
```

说明：因 POST + EventSource 不兼容（EventSource 只支持 GET），统一用 fetch + ReadableStream 解析 SSE 帧；解析器必须容忍半包（缓冲区按空行分帧）与 \r\n 行尾。

#### 4.4.3 历史回放

打开历史会话时，用 `/api/sessions/{id}/runs/{run_id}` 取 steps，喂给**同一个时间线组件**渲染（无动画、一次性展开），保证实时与回放视觉一致。

### 4.5 知识库管理页

- 上传区：拖拽 + 点击选择，多文件排队上传；接受的扩展名在前端先过滤；
- 文档表：文件名、大小、解析器、状态徽标（pending 灰/parsed 蓝/indexed 绿/failed 红/unsupported 橙）、分块数、操作（重建、删除）；
- failed 行可展开 error 原因；每 3s 轮询列表直到没有进行中任务（页面不可见时停止轮询）。

### 4.6 学习路径页（`#/path`）

只读视图。**构建不在页面上触发**——一次抽边要调 LLM、几十秒且花钱，只能命令行跑 `scripts/build_learning_path`（ADR-7）。

- 工具条：章节下拉（选项来自 `/api/path` 的 `chapters`，只列真正有知识点的章 + "全部"）、知识点搜索框（本地建议下拉，选中后收起但保留名字）、分层/环形布局切换；
- 主画布（`components/path-graph.js`）：`layout:'none'` + 手工坐标，**层号由后端 `/api/path` 的 `layer` 给定，前端只排版不重算拓扑**——拓扑逻辑留一份实现，前端再跑一遍迟早跟后端对不上；同层节点超过 8 个切子列，避免孤立节点拉成竖长条；
- 三态视觉（颜色 + 文字双通道，不允许只靠颜色区分，见 §2）：`planned` 必修链（深绿描边，标签"· 必修链第 N 步"）> `touched` 已触达（浅绿描边，标签"· 已触达 N 次"）> `plain` 未触达（灰描边，标签"· 未触达"）；
- 点击节点 → 右侧抽屉：描述、类型、所属章、度数、触达次数、"规划到该知识点"；规划结果既出现在抽屉步骤列表（带 `reason`），也在图上按链序点亮并编号；
- 性能护栏：手机端 `limit=20`、桌面 `limit=40`；环形布局仅在 ≤20 节点时开放，超过强制回落分层（30 个以上必然压叠）；
- 空态：无节点 → "尚未物化知识点 / 该范围内没有已归章的知识点" + 构建命令；有节点无边 → 顶部 warn 条"还没有前驱关系"，图照常画（知识点本身有价值）。

### 4.7 数据大屏（`/screen`）

- **画布**：`screen-root` 固定 1920×1080，`screen.js` 按 `min(w/1920, h/1080)` 等比 `scale` 并居中，`overflow:hidden`。投影仪、笔记本、F11 全屏都是同一构图，不做响应式重排；
- **数据两条线**：`/api/screen/overview` 每 30s（数字卡 + 5 张统计图 + 跑马灯），`/api/graph` 每 5min（中央图谱，300 节点全量力导重排不能每 30s 跑一次）；取数失败 15s 后重试；
- **7 数字卡**：文档/实体/关系/分块/会话/运行 + 知识点触达覆盖率。数字用 rAF 滚动 800ms；覆盖率把 rate 放大到万分位再滚动，滚动过程始终是整数、落位才格式化成两位小数百分数；`total=0` 时隐藏进度条并显示"尚未物化知识点"，不画一条假 0%；
- **6 张图**：中央图谱、实体类型玫瑰图（10 类就地标注必压叠 → 竖排图例）、14 日趋势面积图、工具雷达（轴名截断防顶出面板）、章节条形、高频实体横向条；
- **降级单元是"单张图"**：某图取数或 `setOption` 抛错只让它自己显示占位文字，其余照常。注意 `echarts.init()` 会清空容器 DOM，HTML 里写的占位会被一起带走 → 脚本在 init 后补建占位浮层；
- **聚焦轮播**：每 8s 换一类实体，`dispatchAction` 高亮其邻接。**未做自动 roam**——力导收敛后坐标已冻结，平移缩放会让标签与节点脱钩；
- **图谱护栏**：`/api/graph?limit=500` 取数，按度数截前 300 节点渲染；
- 全站字号下限 16px，`tabular-nums` 防数字滚动时抖动。

## 5. 通用交互与状态规范

| 状态 | 规范 |
|---|---|
| 加载 | 按钮 loading 禁用重复提交；首屏数据用骨架块，不用全屏遮罩 |
| 空态 | 每个列表/画布都有空态插画位（用简洁 SVG 图标）+ 一句引导文案 |
| 错误 | 就近红色提示条 + 可执行动作（重试/重新上传）；不使用 alert |
| 成功 | 轻提示 toast，2s 自动消失 |
| 断网/API 异常 | 顶部状态点变红，悬停显示原因；进行中的 SSE 允许一键重试 |

## 6. 静态资源与目录

```
static/
├─ index.html                 # 工作台（浅色，六个视图）
├─ screen.html                # 数据大屏（深色，1920×1080 等比缩放）
└─ assets/
   ├─ css/app.css             # 工作台设计令牌 + 通用类
   ├─ css/screen.css          # 大屏令牌，与 app.css 互不引用
   ├─ js/
   │  ├─ app.js               # Vue 应用、Tab 路由、全局 store
   │  ├─ api.js               # fetch JSON 封装 + postSSE
   │  ├─ ui.js                # 跨视图小工具（toast、时间格式化、UI.isPhone()）
   │  ├─ components/          # graph-layout（跨端共用）、graph-view、path-graph、
   │  │                       timeline、source-card
   │  ├─ views/               # overview / graph / path / rag / agent / library
   │  └─ screen/screen.js     # 大屏渲染与轮询，不依赖 Vue
   └─ lib/                    # vue.global.prod.js、echarts.min.js 本地兜底
```

- **全局资源版本号**：两个 HTML 共用一个 `?v=mNN`，改过任一 JS/CSS 必须**两页同时 +1**，否则演示时吃到旧缓存。该约束由 `tests/test_screen_charts.py` 静态钉住；
- CDN 地址固定版本号（vue@3.4、echarts@5.5），`lib/` 放本地副本，CDN 加载失败时切换本地（IIFE 判空，符合无白屏降级要求）；
- 不引入 TailWind/Element 等构建型依赖。

## 7. 演示友好性专项

1. 所有按钮/卡片文案面向"老师观看"场景，避免技术黑话（工具名旁给中文名，如"子网计算器"）；
2. 时间线默认字号偏大一档（13px），投影到屏幕可读；
3. 预置问题快捷 chips（样例来自 05 号文档 §6），点击即发送，避免现场打字；
4. 关键结果（子网参数、命中路由、DNS 记录）用结构化表格突出，保证 3 米外可见；
5. 页面切换无白屏：视图常驻、切换只显隐不重新请求（图谱数据缓存，手动刷新）；
6. 投屏走 `/screen`：屏上每个数字都是接口实时聚合的结果，不放假数据、不放静态兜底数字；取数失败的图保留占位文字而不是显示 `0`——`0` 会被读成"系统里真的没有"。
