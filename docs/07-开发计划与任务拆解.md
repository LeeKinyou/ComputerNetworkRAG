# 07 · 开发计划与任务拆解

> 版本 v0.1 ｜ 2026-09-08 ｜ 状态：待评审
> 本计划按 writing-plans 规范编写：每个任务给出文件、对外接口与独立验收方式；执行时逐项勾选。
> 上游基线：01–06 号文档。**Goal：交付可现场演示的单进程课程智能问答 MVP。**

## Global Constraints（全局约束，每个任务默认遵守）

- Python 3.12 锁定，统一用 uv 管理环境与依赖（`uv sync` 安装、`uv run` 执行、`uv add` 加依赖）；依赖以 02 号文档 §5 选型表为准，不自行新增重依赖；
- 单进程、同源静态托管；不引入任何外部数据库/中间件/容器（LangGraph 检查点同样是本地 SQLite 文件）；
- 密钥只从 `app/config.py` 读取；新增配置项必须同步更新 `.env.example` 与 02 号文档 §7；
- 智能体编排固定 LangChain/LangGraph 1.x：统一 `langchain.agents.create_agent`，不写 0.x AgentExecutor、不手工拼 StateGraph；框架只允许出现在 `builder.py`/`runner.py`，业务工具禁止 import LangChain；
- 模块/端点/事件/工具/表名必须与 03/04/05 号文档一致；变更先改文档；
- 纯算法工具（subnet/lpm/number）必须配 pytest 用例；提交前本地跑通；
- 每个任务结束时更新本文件勾选状态并提交一次 git commit。
