## 1. 项目一句话说明

面向"计算机网络"课程的单机演示系统：以课程知识图谱为展示面，提供 RAG 课程问答与 ReAct 智能体问答（智能体可调用计算机网络相关工具，且每一步推理/操作过程可视化）。**单进程部署、无外部数据库与中间件、前端同源托管**，一条命令即可启动演示。

## 3. 全局约定（所有文档一致遵守）

### 3.1 技术基线

- Python 3.12（锁定）；依赖与虚拟环境由 **uv** 管理（`pyproject.toml` + `uv.lock`，`uv sync` 一键安装、`uv run` 执行）；后端 FastAPI + uvicorn；RAG/知识图谱引擎 LightRAG（`lightrag-hku`）。
- 智能体编排固定使用 **LangChain/LangGraph 1.x**：直接用预构建 ReAct（`langchain.agents.create_agent`），不自写编排循环；检查点用本地 SQLite 文件。
- 前端 Vue 3 + ECharts 均通过 CDN 引入，**不使用 npm 构建工程**，由 FastAPI 同源托管静态文件。
- 进程外唯一外部依赖：OpenAI 兼容的 LLM / Embedding API（密钥仅写入项目根目录 `.env`）。
- 不部署任何数据库/中间件服务：知识数据由 LightRAG 默认本地文件存储承担，应用数据由单文件 SQLite 承担。

### 3.2 命名约定

- 后端包名统一为 `app`；服务类后缀 `Service`（如 `AgentService`）；工具文件小写蛇形（如 `subnet.py`）。
- API 前缀统一 `/api`；SSE 端点路径以 `/chat` 结尾。
- SSE 事件名、工具名、文档中出现的模块/端点/表名必须与 03–05 号文档完全一致，不得各写各的。

### 3.3 优先级标记

- **P0（MVP 必做）**：保证演示闭环的最小功能。
- **P1（接口预留）**：抽象与注册位先建好，允许返回"未启用"，后续迭代填充。
- **P2（远期）**：仅在文档中记录方向，MVP 不写占位代码以外的内容。

### 3.4 术语表

| 术语 | 含义 |
|---|---|
| RAG | 检索增强生成：先从课程知识库检索相关片段，再交给大模型生成答案 |
| 知识图谱（KG） | 从课程文档中抽取的实体（如"TCP""滑动窗口"）与关系构成的网络 |
| LightRAG | 香港大学开源的图增强 RAG 框架，本项目的检索与图谱引擎 |
| ReAct | Reason + Act：大模型"思考—调用工具—观察结果"循环推进直到作答 |
| LangGraph | LangChain 的智能体编排运行时；本项目用其 1.x 预构建 `create_agent`（model ⇄ tools 循环图） |
| HITL（人工审批） | Human-in-the-loop：工具执行前暂停，人工批准/改参/拒绝后从断点继续 |
| Checkpointer | LangGraph 状态检查点（本项目用本地 SQLite 文件），中断续跑的前提 |
| SSE | Server-Sent Events，服务端单向流式推送，本项目用于推送回答 token 与智能体步骤 |
| Function Calling | OpenAI 兼容接口的工具调用机制，ReAct 的每一步 Action 由其结构化产出 |
| CIDR | 无类别域间路由表示法，如 `192.168.1.0/24` |
| LPM | 最长前缀匹配，路由表查表的核心算法 |
| Parser | 文档解析器，把 md/docx/pdf/pptx 统一转成 markdown 文本 |
| Trace | 一次智能体运行的完整步骤记录，可落库回放 |
