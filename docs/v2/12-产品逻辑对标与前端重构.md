# 产品逻辑对标与前端重构方案

> 版本：v1（2026-11-18）
> 范围：`frontend/` 信息架构与页面逻辑重构，不涉及后端接口实现。
> 目的：把当前"数据展示型后台"改成"任务导向的课程工作台"，用于导师演示。

---

## 0. 结论

当前系统的视觉已经接近大厂水平，真正落后的是**产品单元**：

- 现在是按"数据实体"组织：文档、图谱、统计、会话；
- 2026 年的办公与教学产品按"任务 / 项目"组织：一个任务有上下文、有计划、有产物、有回流。

因此本轮不改视觉语言，只改三件事：

1. **以任务为中心**：一次问答 = 一个可命名、可回看、可继续、可审批的 Task。
2. **产物一等公民**：答案、计算卡、对比表、笔记、练习、图谱子图都能保存、复用、导出。
3. **用完有回流**：答完留下笔记/错题/掌握度；教师端能看到班级学情。

## 1. 外部对标（2026）

### 1.1 办公产品

| --- | --- | --- |

| 飞书多维表格智能体 | 业务对象本身 | 智能体嵌在表格/评论/侧边栏，不在独立聊天页；支持定时与记录变更触发 |

| WPS 灵犀 | 左文档 / 右对话 | 同屏改稿、改动可回退；交付可编辑 Word/Excel/PPT；任务列表 + 项目/文件空间 |
| 腾讯 ima | 知识库 + copilot | 记忆（用户档案/长期记忆/经验技巧）；知识库直接参与执行；回答内显示"思考过程/计划/已执行命令"；结果写回知识库 |

共性四条：**任务为单位、上下文常驻、产物是一等公民、用完有回流**。

| 清华 | AI 学伴/讲伴/备课助手十大场景；课前把全班高频问题生成"答疑卡"推给教师；生成学习方案时展开图谱，每个知识点配测试并记录进程 |

| 希沃 | 错因图谱、知识图谱、关键能力图谱三张；诊断→干预→反馈证据链；数据回流反哺下节课 |

共性四条：**图谱做导航与诊断、学测评闭环、教师端有学情、学习资产可沉淀**。

### 1.3 Agent UI 范式

| 产品 | 范式 |
| --- | --- |
| Claude | Artifacts 面板：产物是可编辑、可运行的一等对象 |
| ChatGPT 桌面版 | 对话 / 工作 / Codex 三分；项目共享上下文与文件；工作可离开再回来 |
| Cursor | 侧栏持久计划 + 内联 diff + 接受/拒绝 |
| Perplexity | 引用 chip 是证明层，可点开溯源 |
| v0 | 渲染结果即对话，版本可分叉 |

一条明确结论：**把聊天窗口当默认形态，是 2026 年 Agent UI 最常见的错误**；长任务必须有持久计划视图、完成通知，并能离开再回来。

## 2. 现有系统诊断

| 页面 | 现状 | 问题 |
| --- | --- | --- |
| 总览 | 4 个统计 + 最近问答 + 演示脚本 | 像运营看板，不回答"我现在该做什么" |
| 智能问答 | 左会话 / 中对话 / 右只读日志 | 没有产物层；引用不可定位；右栏是日志不是工作区；一次问答不是任务对象 |
| RAG 问答 | 链路 + 引用 + 设置 | 与 Agent 页职责重叠，仍是"一次性回答" |
| 知识图谱 | 18 节点 + 详情卡 | 只用来看；无掌握度、不能从节点开始学习/做题/看原文 |
| 学习路径 | 6 章静态进度 | 无"今天学什么、为什么、学完测什么"，不随薄弱点变化 |
| 文档库 | 上传 + 列表 | 文档只是文件，没有切片预览与知识点映射 |
| 个人中心 | 资料 + 统计 + 偏好 | 没有"我积累了什么" |
| 大屏 | KPI + 图谱 + 实时列表 | 展示状态，不展示"正在发生的一件事" |

缺口排序：**产物 > 任务对象 > 回流 > 导航式图谱 > 首页任务化**。

## 3. 新信息架构

### 3.1 产品单元

```text
Course（课程：计算机网络）
  └── Task（任务：一次问答 / 一次复习 / 一次出题）
        ├── Context（课程、章节、文档范围、引用知识点）
        ├── Plan（步骤计划，可勾选）
        ├── Steps（thought / action / observation / approval）
        ├── Artifacts（答案卡 / 计算卡 / 对比表 / 笔记 / 练习 / 图谱快照）
        └── Sources（原文片段，可定位）
```

Artifact 是跨页面复用的对象：问答里生成，进入"我的产物"，可被计划引用，可导出。

### 3.2 导航（7 项）

| 顺序 | 名称 | 路径 | 职责 |
| --- | --- | --- | --- |
| 1 | 工作台 | `/` | 今天做什么：今日任务、待审批、最近产物、继续学习 |
| 2 | 智能问答 | `/chat` | 任务工作台，合并 RAG 与 Agent 两种模式 |
| 3 | 知识图谱 | `/graph` | 导航与诊断：掌握度、知识面板、从节点起任务 |
| 4 | 学习计划 | `/path` | 今日任务化，按薄弱点动态生成 |
| 5 | 知识库 | `/documents` | 文档、切片、索引、知识点映射 |
| 6 | 学情分析 | `/insights` | 教师视角：高频问题、薄弱点、错因、一键出题 |
| 7 | 我的 | `/profile` | 产物、笔记、错题、偏好 |

大屏 `/screen` 独立全屏，从工作台进入。

`/rag` 保留为重定向：`/rag` → `/chat?mode=rag`。

### 3.3 页面地图

```text
工作台 ─┬─ 继续学习 ─→ 智能问答（任务）
        ├─ 待审批 ───→ 智能问答（审批卡）
        ├─ 今日任务 ─→ 学习计划
        └─ 最近产物 ─→ 我的

智能问答 ── 产物 ──→ 我的 / 学习计划 / 知识库
知识图谱 ── 节点 ──→ 智能问答（新建任务）
学情分析 ── 薄弱点 ─→ 学习计划（自动加任务）
```

### 3.4 数据模型（前端）

```ts
type TaskStatus = 'running' | 'waiting_approval' | 'done' | 'failed'
type TaskMode = 'rag' | 'agent'
type Mastery = 'mastered' | 'weak' | 'new'

interface Task {
  id: string
  title: string
  course: string
  chapter?: string
  mode: TaskMode
  status: TaskStatus
  createdAt: string
  question: string
  steps: TaskStep[]
  artifacts: Artifact[]
  sources: SourceRef[]
}

interface TaskStep {
  id: string
  kind: 'thought' | 'action' | 'observation' | 'approval'
  title: string
  detail?: string
  ms?: number
  status?: 'ok' | 'pending' | 'failed'
}

interface Artifact {
  id: string
  kind: 'answer' | 'calc' | 'table' | 'note' | 'quiz' | 'graph'
  title: string
  summary: string
  createdAt: string
}
```

## 4. 逐页改造规格

### 4.1 工作台 `/`

**回答的问题**：今天我该做什么？

结构：

1. 顶部：问候 + 课程切换 + "开始今天的学习"主按钮。
2. 主卡「今日任务」：3 条任务，每条含标题、来源（薄弱点/计划/复习）、预计时长、开始按钮。第一条高亮。
3. 右列「待审批」：1 条，显示动作、影响范围、等待时长、去处理。
4. 下方「继续学习」：当前章节卡，显示上次停在哪、下一步是什么。
5. 右列「最近产物」：3 条，点击进"我的"。
6. 底部「本周节奏」：7 天小柱状，表示学习强度，不做成绩排名。

删除：4 个大统计卡、演示脚本 2×2。

### 4.2 智能问答 `/chat`

**回答的问题**：我正在解决什么问题，进展到哪，能拿走什么？

三栏：

- **左 232px｜任务列表**
  - 顶部分组：今天 / 本周 / 更早。
  - 每条任务显示标题、模式徽章（快速/深度）、状态点。
  - 底部"新建任务"。
- **中｜对话主线**
  - 顶部任务头：标题、课程/章节 chips、模式切换（快速检索 / 深度智能体）、审批状态。
  - 用户消息：右侧气泡。
  - 助手消息：
    - 回答正文（可折叠长文）。
    - **内联步骤卡**：默认收起，显示"N 步 · 761ms · 3 次工具调用"，展开后是 thought/action/observation 时间线，action 卡显示工具名、参数、耗时、结果摘要。
    - **内联产物卡**：计算题给地址空间条 + 前缀调节 + 结果重算；协议题给对比表；流程题给时序图。
    - 底部操作条：存为笔记 / 出 3 道题 / 加入学习任务 / 复制。
  - 审批中断卡：橙色边，列出待执行动作与影响，按钮"批准 / 修改 / 拒绝"。
- **右 320px｜三标签**
  - 计划：todo 列表（完成打勾、进行中高亮），底部显示总耗时。
  - 产物：卡片列表，每张有类型徽章与操作。
  - 来源：引用片段，显示文档、位置、分数；点击后左侧原文定位并高亮。
- **底部输入**：`@` 引用文档/知识点 + 模式切换 + 发送。

删除：只读"执行轨迹"面板、静态会话列表。

### 4.3 知识图谱 `/graph`

- 节点颜色 = 掌握度：已掌握（绿）、薄弱（橙）、未学（灰蓝）；选中节点有光晕。
- 顶部：搜索、筛选（全部/薄弱/未学）、"按章节"视图切换。
- 右侧知识面板（随选中变化）：
  - 掌握度与最近一次作答时间；
  - 一句话定义 + 原文出处（可点）；
  - 相关知识点 chips（点击跳转）；
  - 相关题目 2 条（可"去练习"）；
  - 底部主按钮："针对这个知识点问 AI"→ 新建任务。
- 图例改为"掌握度"而非"关系类型"（关系类型放次行小字）。
- 保留固定径向布局，避免节点跑出画布。

### 4.4 学习计划 `/path`

- 顶部：本周目标（3 个任务 / 2 小时）+ 进度环。
- 主区「今日」：3 张任务卡（复习薄弱点、完成章节、自测），每张有"为什么给你这条"的一句话依据。
- 下方「章节主线」：保留 6 章，但增加"掌握度"列与"预计完成时间"，进行中章节展开显示 3 个知识点状态。
- 右列「调整计划」：目标时长、难度、是否包含实验，改后即时重排（前端模拟）。

### 4.5 知识库 `/documents`

- 顶部：知识库概览（文档数、分块数、覆盖章节、索引版本）。
- 上传区保留，但增加"解析后预览"：类型、分块、覆盖知识点。
- 文档表增加两列：**覆盖章节**、**切片质量**（好/待优化）。
- 右侧「切片预览」：选中文档后显示 3 条切片（原文 + 所属知识点），可"重建索引"。

### 4.6 学情分析 `/insights`（新页）

教师视角，演示杀手锏：

- 顶部：班级、时间范围、导出。
- 三张卡：本周提问数、高频问题 Top 3、薄弱知识点 Top 3。
- 「知识点掌握」横向条形：章节维度，红/黄/绿。
- 「错因分布」：概念混淆 / 步骤遗漏 / 计算错误 / 读题偏差。
- 「一键动作」：把 Top 3 薄弱点生成练习、生成答疑卡、推送学习任务。

### 4.7 我的 `/profile`

- 左：资料卡（保留）。
- 右：
  - 资产统计（产物 / 笔记 / 练习 / 错题）；
  - 「我的产物」列表（类型、来源任务、时间、导出）；
  - 「学习记录」；
  - 「偏好」（主题、Top-K、快捷键 Ctrl K）。

### 4.8 大屏 `/screen`

改为"一个任务正在发生"的视角：

- 左：当前任务标题、模式、步骤时间线（实时推进）。
- 中：图谱 + 当前命中的知识点高亮。
- 右：本次产物预览（计算卡/答案）、待审批提醒、今日累计。
- 顶部保留时钟与退出。

## 5. 组件与设计规范

新增组件：

| 组件 | 用途 |
| --- | --- |
| `TaskCard.vue` | 今日任务卡（标题、依据、时长、开始） |
| `StepTimeline.vue` | 内联步骤时间线（可折叠） |
| `ArtifactCard.vue` | 产物卡（类型、摘要、操作） |
| `PlanList.vue` | 计划 todo |
| `SourceList.vue` | 引用片段 + 定位 |
| `ApprovalCard.vue` | 审批中断卡 |
| `SubnetArtifact.vue` | 子网计算交互卡 |
| `MasteryBadge.vue` | 掌握度徽章 |

规范：

- 沿用现有语义令牌与圆角三档（18 / 12 / pill），不新增视觉语言。
- 深色模式沿用 `.dark` 令牌，组件不得写死颜色。
- 所有可操作对象必须有 hover 与 focus 态；不用纯图标传达状态。
- 文案用动宾结构："存为笔记""去练习""加入今日任务"，不写"提交""确定"。

## 6. 验收清单

演示脚本（90 秒）：

1. 工作台看到 3 条今日任务，点第一条"继续第 3 章"。
2. 进入问答，任务头显示课程/章节，右栏计划已有 4 步。
3. 提问子网问题，步骤卡展开，工具调用可见。
4. 得到计算产物，改前缀从 /27 到 /28，结果与地址条同步变化。
5. 点"存为笔记"，右栏产物 +1，回工作台"最近产物"出现。
6. 去图谱，该知识点变为"已掌握"，节点颜色变化。
7. 切学情分析，看到班级薄弱点，一键生成练习。
8. 大屏展示同一任务的运行视角。

逐项检查：

- [ ] 所有页面无"只读日志"式面板
- [ ] 每个回答都有可操作产物或明确"无可操作产物"
- [ ] 引用可点并定位
- [ ] 任务状态在列表、头部、工作台三处一致
- [ ] 深色模式下无低对比文本
- [ ] 1440×900 一屏不溢出（长页允许滚动）
- [ ] 所有按钮文案为动宾结构
