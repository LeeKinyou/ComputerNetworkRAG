# V2 前端页面与交互规范

日期：2026-10-15。状态：待实现。技术沿用 Vue 3/TypeScript/Vite/Router/Pinia/Element Plus，契约以 [05](./05-API与事件契约.md) 为准。

## 1. 目录与协作边界

```text
frontend/src/
  app/                 # A：入口、Router、鉴权、布局、全局错误
  api/                 # A：client、生成类型；B/C 各写业务 API 封装
  components/          # A：通用空态/错误/加载；共享组件协调后修改
  features/
    identity/ courses/ # A
    tutoring/ sources/ # B
    practice/ learning/# C
  pages/               # 路由页面，按下表归属
  styles/              # A：设计令牌、阅读排版
```

A 负责公共入口和依赖文件；B/C 通过模块路由导出接入，避免多人同时改 Router 和 lockfile。每人负责对应业务页面、API 封装、mock 和必要交互测试，不存在“第三人完成后才开始前端”的等待关系。

## 2. 路由与页面交付

| 路由 | 主责 | 主要内容 | API |
| --- | --- | --- | --- |
| /login | A | 账号、密码、提交与错误；登录后回原页面 | auth/csrf、login、me |
| / | A，C 提供摘要组件 | 继续练习、待复习、近期活动；无数据时入门入口 | courses、learning/summary |
| /courses | A | 课程列表与空态 | courses |
| /courses/:id | A，B 提供正文/助教组件 | 左侧章节，中间来源/知识点，右侧可展开助教 | chapters、concepts、documents、content |
| /chat/:sessionId? | B | 会话历史、输入、上下文标签、运行状态/卡片 | chat-sessions、runs、events |
| /sources/:chunkId | B | 真实来源、版本、定位和邻近原文 | sources/{id} |
| /practice | C | 课程、章节、知识点、题型筛选与选题 | questions、attempts |
| /attempts/:id | C | 题目、草稿、提示、显式提交 | attempts、answers、hints、submit |
| /attempts/:id/report | C | 排队、评分中、待复核、失败或版本化报告 | report、grading-runs |
| /mistakes | C | 错因/知识点筛选、证据链接、再练习 | mistakes |
| /reviews | C | 复习建议、接受、到期项、完成/再练习 | review-proposals、review-plans |
| /admin/content | A 布局，B 文档面板，C 题库面板 | 课程维护、上传/建库/发布、题库审核 | admin 对应接口 |
| /admin/jobs | A | 脱敏任务列表、状态与安全重试入口 | admin/jobs |

路由守卫仅提供体验，实际授权由服务端实施。访问不存在/不属于本人的资源统一“资源不存在或不可访问”，不靠猜角色显示数据。管理入口只有 admin 显示。

## 3. 共享组件与设计规则

- AppShell/CourseSidebar/AsyncState 由 A；CitationLink/SourcePreview/AgentPanel/RunProgress/CalculationCard 由 B；QuestionRenderer/AnswerEditor/ReportCard/ReviewCard 由 C。
- 默认浅色阅读界面；统一 spacing、font、color、radius 令牌。正文建议最大宽度 880px，移动端单列，课程侧栏和助教抽屉切换；表格允许横向滚动。
- 表单有标签、错误与键盘焦点；按钮加载时防止本地重复点击。来源、评分状态和错误不只依赖颜色表达。
- Markdown 关闭原始 HTML，链接协议白名单，外链安全打开；来源文本和模型回答都视为不可信输入。禁止 v-html 直接渲染原始回答。
- 来源显示标题、版本和页/章节；page=null 时不显示“第 0 页”。签名 URL 不写入本地长期状态。
- 图谱和任务轨迹默认折叠；不显示模型内部思维链。管理诊断也不能渲染凭据、答案快照或私聊原始日志。

## 4. 服务端状态与本地状态

Pinia 保存登录用户、当前课程、UI 偏好和少量运行索引；题库/报告/来源等服务端资源按 API 加载，避免多份副本。API client 统一 credentials、CSRF、request_id、错误体与取消请求处理。

OpenAPI 生成 TypeScript DTO，业务代码引用生成类型，不手写同名接口；生成文件禁止直接修改。B/C 的业务封装只处理请求与领域响应，不再包装第二套错误体。

草稿本地编辑态与服务端 version 分开。可在停止输入后 800ms 防抖保存，离开前等待当前保存或提示未保存；失败保留本地内容，刷新恢复以服务端为准并明确本地未同步状态。若使用本地草稿缓存，key 包含 user/attempt，退出清除，不能跨账号恢复。

提交顺序：校验输入 → 等待保存成功 → 展示不可编辑确认 → 用最新 version 和稳定 Idempotency-Key 提交。网络超时不新建答卷/新 key；先查询该答卷状态，再用原 key 重试。409 保留编辑内容并要求重新加载/比较，禁止自动覆盖服务端。

## 5. 助教运行状态

| status | 页面行为 |
| --- | --- |
| queued/running | 显示阶段和取消入口，禁用同会话新 run；可切换其他页面 |
| waiting_user | 显示服务端问题，以 input_id 继续；仍占用会话 |
| waiting_approval | 展示具体操作摘要、确认/拒绝；不允许编辑参数后沿用旧审批 |
| completed | GET run 读取完整结果，显示引用和卡片 |
| partial | 同时展示已完成与未完成项；继续新任务必须显式发起 |
| failed/cancelled | 展示安全原因；保留已持久化结果，允许显式新任务 |

进入已有会话时先 GET 历史和当前相关 run 状态，再连接事件；不能仅根据内存中的“正在生成”判断任务是否存在。页面 context 标签显示当前章节/题目/报告并可移除，提交只传 ID。

SSE 按 (run_id,seq) 去重，游标持久到 sessionStorage（包含 user/run）；刷新用 after_seq。断线指数退避，上限 10 秒，持续失败改每 3 秒 GET run，避免双通道无限叠加。终态主动关闭 SSE/轮询并重读完整结果，410 直接走 history_url；离开页面断开订阅，job 继续。

answer.delta 仅用于当前显示，最终 answer_markdown 覆盖为规范结果；刷新后不能把不完整缓存当最终答案。引用无法加载时显示“来源暂不可用”，不静默替换为其他版本。

## 6. 练习、报告与复习状态

- QuestionRenderer 按 type 渲染，选项使用稳定 ID；计算题字段/单位来自公开 answer_schema。不得从答案 key 推导表单。
- 提示展示当前级别与已用提示标识；错误请求保留草稿。模型提示不能代替 submit。
- 提交后答案只读。报告 queued/running 时低频查询并展示状态；needs_review 显示待复核，无分数；failed 显示失败，不显示 0 分。
- completed 才渲染总分、分项、错因、来源和参考解答。units/100 仅用于显示，前端不重新计算或覆盖服务端总分。切换历史 revision 有明显标签。
- 复习建议点击“接受”后创建计划；“完成阅读”和“再次练习”分别操作，前者不自动生成正确作答证据。重复题、提示使用、样本不足在学习摘要中明确显示。

## 7. 页面验收

每个页面必须包含加载、空数据、可重试错误、权限失效和成功状态；业务页另覆盖冲突/等待/部分完成。至少验证一次 375px 宽屏的阅读和作答。关键交互测试集中覆盖登录、草稿冲突、重复提交、等待续跑、SSE 重连与退出清理；不为纯展示组件编写机械快照测试。

mock 仅用于开发/测试，构建时显式控制，生产禁止注入。每人提交自己的 fixtures，字段与生成 DTO 校验；共享场景 fixture 的 ID 和版本由 A 协调，不能三套不兼容数据各演各的。
